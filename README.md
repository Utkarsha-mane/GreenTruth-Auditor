# GreenTruth-Auditor
 "Greenwashing" creates a lack of consumer trust. Brands use vague marketing  buzzwords like "eco-friendly" to hide high-carbon supply chains, making it impossible for ethical  consumers to make informed choices. This  tool on parsing product  descriptions or URLs and use NLP to categorize claims as "Vague/Unverifiable" or  "Fact-Based/Certified."
